# Après installation de V13

- Lancer l'action GitHub « Générer le catalogue PokéTracker ».
- Contrôler les journaux : MEG doit fournir 188 entrées ; M1L et M1S doivent être listées séparément (92 entrées chacune selon les références de set).
- Vérifier que `catalog-data.js` n'est plus vide et que `catalog/images/` contient les images.
- Ajouter ensuite les autres séries seulement après validation de leur identifiant officiel dans TCGdex.
- Les prix de marché EUR/JPY nécessitent une source dédiée et ne sont pas fabriqués par le catalogue de cartes.
